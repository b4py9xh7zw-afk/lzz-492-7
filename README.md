# 👕 服装厂计件看板

零第三方依赖的服装厂计件工资看板：**组长录入产量 → 系统按合格/返工/缺料/质检不过分类 → 工人手机端只看自己的今日工资预估 → 月底普通计件与补贴分开导出**。

## 快速开始

```bash
npm start            # 或 node server.js
# 打开 http://localhost:3000
# 自定义端口: PORT=8080 node server.js
```

要求 Node.js ≥ 18（仅使用内置模块，无需 npm install）。

### 默认账号

| 角色 | 入口 | 账号 | 密码 |
|---|---|---|---|
| 组长/管理员 | 「组长 / 管理」 | — | `123456`（登录后在"设置"中修改） |
| 工人 | 「工人查工资」 | `A001`～`A003`、`B001`、`B002` | `1234` |

首次启动自动生成演示数据（工人、款号工序、近两天的产量与补贴）。数据存在 `data/store.json`，删除该文件重启即恢复初始演示数据。

## 业务规则

**四类产量**（每次录入分别填写）：

| 分类 | 是否计件 | 说明 |
|---|---|---|
| 合格 | ✅ 合格数 × 工序工价 | 构成普通计件工资 |
| 返工 | 默认 ❌（可在设置中设返工单价） | 计入产量统计，区分质量 |
| 缺料 | ❌ 不计件 | 按「缺料数 × 缺料补贴单价」自动算**缺料补贴**，可全局关闭 |
| 质检不过 | 默认 ❌（可在设置中设单价） | 计入产量统计 |

- 同一天、同一工人、同一工序只保留一条记录，重复录入为**覆盖更新**（防重复计薪）。
- 录入时把当时的**工价、缺料补贴单价快照**存入记录；以后改价只影响新录入，历史工资不变。
- 手工补贴（全勤奖、加班、餐补等）在「补贴登记」中单独录入。
- 工人端工资预估 = 普通计件 + 缺料补贴 + 手工补贴，每分钟自动刷新。

**隐私隔离**：工人用工号+密码登录，服务端鉴权，`/api/worker/me` 只返回本人数据；工人无法访问名单、看板、导出等任何管理接口（返回 403），彼此看不到对方产量和收入。

## 月底导出（计件 / 补贴分开）

「月底导出」页选择月份后可下载：

1. **`计件工资明细_YYYY-MM.csv`**：逐条产量明细（日期、工号、姓名、款号、工序、工价、合格/返工/缺料/质检不过数量、计件工资），末尾附工人计件汇总。
2. **`补贴明细_YYYY-MM.csv`**：缺料补贴（注明"款号工序 缺料N件 × 单价"）与手工补贴分行列出，末尾附工人补贴汇总。
3. 备选：`工资表_计件与补贴_YYYY-MM.xls` —— 一个工作簿内含「普通计件」「补贴」两个工作表，Excel/WPS 直接打开。

CSV 带 UTF-8 BOM，用 Excel 打开中文不乱码。

## 功能页面（组长端）

- **今日看板**：四类产量总数、计件/补贴金额、工人产量排行、工序产量分布，可切换日期。
- **产量录入**：选工人+款号工序，填四类数量；当天明细表可编辑/删除，工价变动会显示"现价"提示。
- **款号工序工价**：维护款号、工序、计件工价、缺料补贴单价；有历史记录的工序只能停用不能物理删除。
- **工人管理**：工号/姓名/登录密码维护；有记录的工人不可删除。
- **补贴登记**：手工补贴按月份录入与管理。
- **月底导出**：见上。
- **设置**：缺料补贴开关、返工/质检不过单价、管理员密码。

## 目录结构

```
server.js            HTTP 服务 + API + 工资计算 + CSV/XLS 导出（零依赖）
db.js                JSON 文件数据层（data/store.json）+ 初始演示数据
public/
  index.html         登录页 / 管理端 / 工人手机端三视图
  css/style.css      管理端 + 移动端样式
  js/                api 封装、登录、admin 各页、worker 手机页、启动
data/store.json      运行后自动生成的数据文件
```

## 主要接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | /api/admin/login · /api/worker/login · /api/logout | 公开 | 登录/退出，返回 Bearer Token |
| GET | /api/worker/me | 工人 | **仅本人**今日/本月计件与补贴、今日明细 |
| GET | /api/dashboard?date= | 管理员 | 看板汇总 |
| GET/POST/PUT/DELETE | /api/records | 管理员 | 产量录入（按 日期+工人+工序 唯一，POST 为 upsert） |
| GET/POST/PUT/DELETE | /api/styles | 管理员 | 款号工序工价 |
| GET/POST/PUT/DELETE | /api/workers | 管理员 | 工人 |
| GET/POST/DELETE | /api/subsidies | 管理员 | 手工补贴 |
| GET/PUT | /api/settings | 管理员 | 工资规则、管理员密码 |
| GET | /api/export/piece.csv · subsidy.csv · payroll.xls?month=YYYY-MM | 管理员 | 月度导出 |

> 部署提示：生产环境建议放在 Nginx/HTTPS 反向代理之后；当前数据层为 JSON 文件（适合单车间规模），接口层已按资源划分，后续可平滑替换为 MySQL/PostgreSQL。
